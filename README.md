# OMATO Food Delivery Dashboard – Project Description

## 1. Project Overview

The **OMATO Food Delivery Dashboard** is an interactive **Power BI Dashboard** created to analyze and monitor the performance of a food delivery business. It provides insights into transactions, customer preferences, delivery performance, product demand, and payment methods through visually engaging reports.

---

## 2. Business Objective

The main purpose of this dashboard is to help management track and improve:

1. Order performance
2. Monthly sales trends
3. Popular food items
4. Delivery efficiency
5. Payment preferences
6. Customer behavior
7. Category-wise demand

---

## 3. Key Performance Indicators (KPIs)

1. **Total Quantity:** 9.56K

   * Total items ordered by customers.

2. **Transactions:** 1.71K

   * Total number of orders placed.

3. **Average Quantity:** 5.58

   * Average items per transaction.
